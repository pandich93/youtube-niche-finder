# Code of conduct

niche-finder follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
This page is the short version; the full text applies.

## What we expect

- Be kind and patient, including with people who are new to the project, to
  Python or to English.
- Criticise code and ideas, not people. Assume good intent and ask before you
  conclude.
- Accept that a maintainer may say no to a change; the reasons will be given.

## What is not accepted

- Harassment, insults, slurs, or sexual language and imagery.
- Personal or political attacks, trolling, and deliberate derailing.
- Publishing someone's private information (an address, an email, a channel
  they did not make public) without their permission.

This covers issues, pull requests, reviews, commit messages and any other
place where you speak for the project.

## Reporting

Write to the maintainer, [@pandich93](https://github.com/pandich93), using the
contact on their GitHub profile, or use GitHub's
[report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
form for content on GitHub. Reports are read in private and the reporter's
name is not shared.

A maintainer may edit or remove comments, close issues and pull requests, and
block someone from the repository for a while or for good, depending on how
serious it was and whether it is repeated. Security problems are not reported
here: see [SECURITY.md](SECURITY.md).
